現在のマインドマップアプリのバックエンド（Cloudflare Workers）とフロントエンドの通信処理を、`hono` を用いてリファクタリングし、Hono RPCによるエンドツーエンドの型安全な通信を実現してください。
以下の【要件】を満たすように、ファイルの作成・修正を行ってください。

【要件1: 依存関係の追加】
`package.json` に `hono` を追加してください（`npm install hono` を想定）。

【要件2: src/worker.ts の Hono 化】
現在の生の `fetch` イベントハンドラでルーティングしている `worker.ts` を、Hono を使って書き換えてください。
1. `import { Hono } from 'hono'` を追加し、`const app = new Hono<{ Bindings: Env }>()` で初期化してください。
2. APIのルートとして `const route = app.basePath('/api')` などを定義し、以下のエンドポイントを実装してください。
   - `.get('/mindmaps', ...)`
   - `.post('/mindmap', ...)` (JSONボディを受け取る)
   - `.get('/mindmap/:id', ...)`
   - `.put('/mindmap/:id', ...)`
   - `.delete('/mindmap/:id', ...)`
3. D1データベースへのアクセスは `c.env.DB` を通じて行ってください。
4. API以外のリクエスト（Reactの静的ファイル）については、Honoの `app.get('*', (c) => c.env.ASSETS.fetch(c.req.raw))` などの仕組みで `ASSETS` から配信できるようにフォールバック処理を実装してください（SPA用の `/index.html` フォールバックも考慮してください）。
5. 最後に `export type AppType = typeof route;` としてRPC用の型をエクスポートし、`export default app;` でWorkerとしてエクスポートしてください。

【要件3: APIクライアントの定義 (src/utils/cloudMindmaps.ts)】
1. `hono/client` から `hc` をインポートしてください。
2. `src/worker.ts` から `AppType` をインポート（type-only import）してください。
3. `export const client = hc<AppType>('/')` のようにHono RPCクライアントを初期化してエクスポートしてください。既存のURL文字列を生成する関数（`getCloudMindmapsUrl`など）は削除して構いません。

【要件4: useStore.ts の fetch 処理のリファクタリング】
`src/store/useStore.ts` 内にある、バックエンドとの通信を行っている以下の4つのアクションを、生の `fetch` から Hono RPC (`client.api...`) を使った呼び出しに書き換えてください。
- `fetchCloudMindmaps`
- `deleteFromCloud`
- `loadFromCloud`
- `saveToCloud`
※ Hono RPCの仕様に従い、`await client.api.mindmaps.$get()` や `.json()` メソッドを呼び出して型安全にデータを受け取るように修正してください。
