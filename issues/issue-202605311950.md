現在のマインドマップアプリにおいて、org-mode形式でエクスポート・インポートを行った際、ノードがルートの「左側」にあったか「右側」にあったかの位置情報が失われてしまう問題を修正してください。
以下の要件を満たすように、エクスポートとインポートのロジックを修正してください。

【要件1: エクスポート処理の修正 (src/utils/exportOrgMode.ts)】
1. `buildHeadings` 関数でルートノードの直接の子ノード（`level === 2`）を処理する際、そのノードの `position.x` の値を確認してください。
2. `position.x < 0` （左側）であれば、出力する見出しのラベル文字列の末尾に `:LEFT:` タグを付与し、それ以外（右側）であれば `:RIGHT:` タグを付与してください。（例: `** アイデア :LEFT:`）
※ `org-toolkit` の仕様が不明な場合は、単純に `normalizeLabel` した文字列にスペースを空けて `:LEFT:` を結合する形で構いません。

【要件2: インポート処理の修正 (src/utils/orgModeGraph.ts または importOrgMode.ts)】
1. `headingToLabel` やノード生成のループ内で、見出しテキストの中に `:LEFT:` または `:RIGHT:` というタグ文字列が含まれているか正規表現などで判定してください。
2. 実際の `data.label` に設定するテキストからは、それらのタグ文字列（および余分な空白）を取り除いたクリーンな文字列を使用してください。
3. ルートノードの直接の子ノード（`level === 2`）を生成する際、タグが `:LEFT:` であった場合はノードの初期 `position` を `{ x: -250, y: 0 }` に設定し、`:RIGHT:` であった場合（またはタグがない場合）は `{ x: 250, y: 0 }` に設定してください。
※これ以外のノード（level 3以降など）の初期位置は `{ x: 0, y: 0 }` のままで構いません。

【要件3: 前提の確認】
インポート後のストア側（`useStore.ts`）の `applyAutoLayout` 内にある `splitRootChildIds` 関数は、ルート直下のノードの `position.x` の絶対値が 1 より大きい場合、手動で指定された左右の配置を尊重する仕様にすでになっています。そのため、要件2で初期X座標さえ設定すれば、自動的に左右の配置が復元されます。
