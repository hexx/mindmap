MindMapNodeコンポーネントのキーボードイベント伝播の不具合修正

現在の `src/nodes/MindMapNode.tsx` において、マインドマップ上のノードを選択した状態でTabキーやEnterキーを押しても、ノード追加のショートカットが発火しない不具合が発生しています。
原因は、カスタムノードのルート要素でキーボードイベントの伝播を止めてしまっていることです。以下の修正を行ってください。

【修正内容】
1. `MindMapNode.tsx` の return 内にある、一番外側のルート `div` 要素から `onKeyDown={stopCanvasEvents}` と `onKeyUp={stopCanvasEvents}` の2行を削除してください。
2. ダブルクリックによるインライン編集用の `input` 要素に設定されている `onKeyDown` と `onKeyUp`（`event.stopPropagation()` を含んでいるもの）は、編集中のキーボードイベントを正しく止めるために必要なので、そのまま残してください。
