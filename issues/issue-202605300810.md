d3-hierarchyを用いたマインドマップの自動整列（オートレイアウト）機能の実装

マインドマップのノードが散らかってしまった際に、ボタン一つでツリー状に綺麗に整列する機能を実装してください。

【前提】
- この機能には `d3-hierarchy` を使用します。事前に `npm install d3-hierarchy` と `npm install -D @types/d3-hierarchy` を実行済みであるという前提でコードを出力してください。

【要件1: useStore.ts の拡張】
1. ストアに `applyAutoLayout: () => void` を追加してください。
2. 現在の `nodes` と `edges` を元に、`d3.stratify()` を用いてルートノード（`ROOT_NODE_ID`）を頂点とする階層データ（hierarchy）を構築してください。
3. `d3.tree()` を用いて、各ノードの x座標・y座標を計算してください。ノード間の余白を確保するため、`nodeSize` はおおよそ縦 `100`、横 `300` 程度に設定してください。
4. マインドマップは左から右へ広がるため、d3が計算した `x` 座標を y座標として、`y` 座標を x座標として反転させて各ノードの `position` を更新してください。

【要件2: App.tsx または MobileToolbar.tsx への組み込み】
1. 画面の邪魔にならない位置（エクスポートボタンの横やツールバー内など）に「整列」ボタンを追加してください。
2. ボタンをクリックした際に、ストアの `applyAutoLayout` を実行するようにしてください。
