# 課題解決プロンプト: マインドマップアプリにUndo機能を実装する

## 1. 役割定義 (Persona)
あなたは高度なソフトウェアエンジニアおよび問題解決のエキスパートです。以下のコンテキストとゴールを基に、正確かつ効率的な実装を行ってください。

## 2. 背景・前提条件 (Context)
- **現状発生している問題**: 現在のマインドマップアプリにはUndo機能が実装されていないため、ユーザーがノードの追加・削除・編集・移動などの操作を誤った場合に、元の状態に戻すことができない
- **技術スタック**: React + Zustand（状態管理）+ React Flow（マインドマップ描画）
- **関連ファイル/コード**:
  - `src/store/useStore.ts` — Zustandストア（ノード・エッジの状態管理）
  - `src/App.tsx` — メインコンポーネント（キーボードイベント処理）
  - `src/nodes/MindMapNode.tsx` — ノードコンポーネント（ラベル編集）

## 3. 解決すべきゴール (Goal & Objective)
- [ ] ZustandストアにUndo/Redoの履歴管理機能を追加する
- [ ] Ctrl+Z（Cmd+Z）で操作をUndoできるようにする
- [ ] Ctrl+Shift+Z（Cmd+Shift+Z）またはCtrl+YでRedoできるようにする
- [ ] 対象操作: ノード追加、ノード削除、ラベル編集、ノード移動（リペアント）
- [ ] 履歴は直近50件程度を保持し、メモリを圧迫しないようにする
- [ ] 既存のテストが壊れないこと

## 4. 期待する成果物 (Output Format)
- `src/store/useStore.ts` にUndo/Redoの状態管理ロジックを追加したコード
- `src/App.tsx` にCtrl+Z/Ctrl+Shift+Zのキーボードショートカットを追加したコード
- 動作確認手順とテストの実行結果
