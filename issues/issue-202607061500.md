# 課題解決プロンプト: テストコードが実装と乖離して全滅している

## 1. 役割定義 (Persona)
あなたは高度なソフトウェアエンジニアです。ユニットテストとE2Eテストの両方を実装と整合させ、CIで確実にパスする状態に修復してください。

## 2. 背景・前提条件 (Context)

### 問題A: `useStore.test.ts` が存在しないメソッドを呼んでいる
- **現状**: `src/store/useStore.test.ts` の `beforeEach` 内で `useStore.setState(useStore.getInitialState(), true)` を実行している
- **原因**: `getInitialState` は `useStore`（zustandストア）に公開されておらず、`createInitialState` はモジュール内の非公開関数
- **結果**: TypeScriptコンパイルが通らず、テストが一切実行できない状態

### 問題B: PlaywrightテストのCSSクラスセレクタがすべて存在しない
- **現状**: `tests/mindmap.spec.ts` で以下の存在しないクラスを参照している:
  - `.main-menu__dropdown`
  - `.main-menu__item`
  - `.main-menu__overlay`
  - `.mindmap-node--selected`
  - `.mobile-toolbar`
- **原因**: 実装コンポーネント（`MainMenu.tsx`, `MindMapNode.tsx`, `MobileToolbar.tsx`）はこれらのCSSクラスを全く付与していない
- **結果**: 12個のE2Eテストがすべて失敗する

### 関連ファイル
- `src/store/useStore.test.ts`
- `src/store/useStore.ts`
- `tests/mindmap.spec.ts`
- `src/components/MainMenu.tsx`
- `src/nodes/MindMapNode.tsx`
- `src/components/MobileToolbar.tsx`

## 3. 解決すべきゴール (Goal & Objective)
- [ ] `useStore.test.ts` を修正し、正しい方法で初期状態にリセットする（例: `useStore.setState(useStore.getInitialState())` 相当の処理に置き換え、必要なら `createInitialState` をエクスポートするか、リセット用のアクションを追加する）
- [ ] PlaywrightテストのCSSセレクタを、実際のコンポーネントが出力するDOM構造に合わせて修正する（`getByRole` や `getByText` など、より堅牢なセレクタを優先）
- [ ] 修正後、`npx vitest run` および `npx playwright test` が全件パスすることを確認する
- [ ] 既存のテストケースの意図（カバレッジ）を維持すること

## 4. 期待する成果物 (Output Format)
- 修正が完了したコード一式
- `npx vitest run` の全件パス結果
- `npx playwright test` の全件パス結果
- 修正方針の簡潔な解説
