Cloudflare Workersへのデプロイ設定とDB（D1）連携の準備

現在のVite + Reactのマインドマップアプリを、Cloudflare Pagesではなく、Cloudflare Workersとしてデプロイするための設定を行ってください。目的は、既存の `.workers.dev` サブドメイン（`mindmap.hogeika.workers.dev`）で公開することと、将来的なデータベース（Cloudflare D1）保存の土台を作ることです。

【要件】
1. 開発用依存関係として `wrangler` をインストールするコマンドを提示してください。
2. プロジェクトのルートディレクトリに `wrangler.toml` を新規作成し、以下の設定を記述してください。
   - `name = "mindmap"` と設定する（これで `mindmap` サブドメインが割り当てられます）。
   - Viteのビルド成果物である `dist` フォルダを静的アセットとして配信するための設定（例: `assets = { directory = "dist" }` または `[site]` バインディング）を追加する。
   - 将来のデータベース保存の準備として、Cloudflare D1のバインディング設定（`[[d1_databases]]`）の雛形をコメントアウトした状態で追記する。
3. `package.json` の `scripts` を更新し、ビルド後にCloudflare Workersへデプロイするコマンド `"deploy": "npm run build && wrangler deploy"` を追加してください（※ `wrangler pages deploy` ではなく `wrangler deploy` を使用します）。
