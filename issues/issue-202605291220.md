React FlowとTypeScriptを用いたマインドマップWebアプリの初期セットアップ

Vite + React + TypeScript環境で、Cloudflare Pagesにデプロイ予定のマインドマップアプリの初期コードを生成してください。
以下の要件を満たす最低限の動作するベース（土台）を作成したいです。

1. Viteでのプロジェクト初期化コマンドを提示してください。
2. React FlowとZustand（状態管理用）のインストールコマンドを提示してください。
3. 画面中央に「ルート（中心概念）」という1つのノードだけが配置された状態の、React Flowの基本的なキャンバスコンポーネント（`App.tsx` または専用コンポーネント）のコードを出力してください。
4. ノードとエッジの状態管理はZustandを使用して実装し、将来的にノードを追加・削除しやすいストアの設計（`useStore.ts`）にしてください。
