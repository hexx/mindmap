React Flowのカスタムノード作成とインラインテキスト編集の実装

初期セットアップされたコードに対して、直接テキストを編集できるマインドマップ専用のカスタムノードを作成し、適用してください。
今後のキーボードショートカット実装の土台となるため、以下の要件を必ず満たしてください。

1. `MindMapNode.tsx` というカスタムノードコンポーネントを作成し、React Flowの `nodeTypes` に登録してデフォルトノードと差し替えてください。
2. ノードをダブルクリックした際に、テキスト表示から `input`（または `textarea`）要素を用いた編集モードに切り替わるようにしてください。
3. 編集モードで文字を入力し、「Enter」を押すかフォーカスを外した（onBlur）際に編集モードが終了し、Zustandのストア内にある該当ノードの `data.label` が更新されるようにしてください。
4. 【重要】編集モード（inputにフォーカスが当たっている状態）の時は、キーボードイベント（EnterやBackspaceなど）がReact Flowのキャンバス全体に伝播しないように、`e.stopPropagation()` などを適切に設定してください。
5. Tailwind CSSを用いて、マインドマップらしくシンプルで枠線のある角丸のデザインにしてください。
