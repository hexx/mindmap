TabキーやEnterキーで新規ノードを追加した際、自動的にインライン編集モードの枠線（Input要素）には切り替わるものの、テキスト入力欄にフォーカスが当たらず、即座に文字を入力し始められない不具合を修正してください。
原因は、`isEditing` が true になった直後のフォーカス処理が早すぎて、React Flowの内部的なフォーカス制御と競合して空振りしているためです。

【要件: src/nodes/MindMapNode.tsx の修正】
1. `MindMapNode.tsx` 内にある、`isEditing` の変更を監視してインプットにフォーカスを当てる以下の `useEffect` を探してください。
   ```typescript
   useEffect(() => {
     if (isEditing) {
       inputRef.current?.focus();
       inputRef.current?.select();
     }
   }, [isEditing]);
   ```

2. この `if (isEditing)` の中身を修正し、`globalThis.requestAnimationFrame` の二重呼び出し（ネスト）でラップした上で、`inputRef.current?.focus()` と `inputRef.current?.select()` を実行するように書き換えてください。
3. これにより、ブラウザが新しいInput要素を完全に描き終わった最も確実なタイミングでフォーカスが当たるようにし、ノード追加後すぐに文字入力ができるシームレスな体験を実現してください。

---

### 💡 修正後の動作
この修正を適用することで、`Tab` で子ノード、`Enter` で兄弟ノードを追加した瞬間、完全にキーボードから手を離すことなく、**そのまま流れるようにタイピングして文字を入力できるようになります。**
