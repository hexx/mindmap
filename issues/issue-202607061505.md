# 課題解決プロンプト: 軽微な問題のクリーンアップ

## 1. 役割定義 (Persona)
あなたは細部にこだわるソフトウェアエンジニアです。以下の軽微だが放置すべきでない問題を一掃してください。

## 2. 背景・前提条件 (Context)

### 問題A: ルートに空の `core` ファイルが存在する
- **ファイル**: `/workspace/core`（0バイト）
- **対応**: 削除する。誤ってコミットされたゴミファイルと思われる

### 問題B: `clearHistory` がデッドコード
- **ファイル**: `src/store/useHistoryStore.ts`
- **内容**: `clearHistory` アクションが定義されているが、コードベースのどこからも呼ばれていない
- **対応**: 必要なさそうであれば削除。将来的に使う可能性があれば残してコメントを付ける

### 問題C: `schema.sql` のINDEXがDrizzleスキーマに反映されていない
- **ファイル**: `schema.sql`, `src/db/schema.ts`
- **内容**: `schema.sql` には `CREATE INDEX idx_mindmaps_created_at ON mindmaps(created_at DESC)` があるが、`db/schema.ts` のDrizzle定義にはインデックスが定義されていない
- **対応**: `db/schema.ts` に `index()` を追加する。または `schema.sql` をDrizzleのマイグレーション出力に置き換える
```ts
// 修正後の schema.ts
export const mindmapsTable = sqliteTable(
  'mindmaps',
  {
    id: text('id').primaryKey(),
    title: text('title').notNull(),
    nodesJson: text('nodes_json').notNull(),
    edgesJson: text('edges_json').notNull(),
    createdAt: text('created_at').notNull(),
    updatedAt: text('updated_at').notNull(),
  },
  (table) => [index('idx_mindmaps_created_at').on(table.createdAt)],
);
```

### 問題D: `package.json` の `radix-ui` 依存が不要の可能性
- **内容**: `"radix-ui": "^1.5.0"` はshadcnのメタパッケージで、shadcn CLIが自動で必要な `@radix-ui/*` を個別にインストールするため、冗長な可能性がある
- **対応**: 実際に使われているか `npm ls radix-ui` で確認し、不要なら削除する

### 関連ファイル
- `/workspace/core`
- `src/store/useHistoryStore.ts`
- `src/db/schema.ts`
- `schema.sql`
- `package.json`
