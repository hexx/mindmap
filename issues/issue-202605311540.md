現在のマインドマップアプリ（Vite + React + Zustand）に対して、自動テストの環境構築とサンプルのテストコードを実装してください。
テストは、ロジック用の「Vitest」と、UI/E2E操作用の「Playwright」の2つを使用します。以下の【要件】を満たしてください。

【要件1: パッケージの追加と設定 (Vitest)】
1. `package.json` の `devDependencies` に `vitest` を追加し、npm scripts に `"test": "vitest"` を追加してください。
2. `vite.config.ts` を更新し、Vitestが動くように `test` オプション（環境設定など）を追記してください。

【要件2: Zustandストアのユニットテスト作成】
1. `src/store/useStore.test.ts` を新規作成してください。
2. `useStore` のロジックをテストするために、以下の3つのケースを実装してください：
   - 「初期状態ではルートノードが1つだけ存在すること」
   - 「addChildNode を実行すると、親ノードと紐づく子ノードとエッジが正しく追加されること」
   - 「removeNode を実行すると、指定したノードとそれに紐づく子孫ノードがすべて削除されること」
※ Zustandのストアをテストする際、各テストの前にストアの状態をリセットする処理（beforeEach）も適切に書いてください。

【要件3: Playwrightの初期設定とE2Eテスト作成】
1. E2Eテスト用に `playwright.config.ts` の雛形を作成してください（ローカルサーバー `http://localhost:5173` を起動してテストする設定を含める）。
2. `tests/mindmap.spec.ts` を新規作成し、以下のE2Eテストシナリオを実装してください：
   - 「ページにアクセスすると、ルートノードが表示されていること」
   - 「ルートノードを選択してTabキーを押すと、新しいノードが追加されること」
3. `package.json` に `"test:e2e": "playwright test"` を追加してください。
