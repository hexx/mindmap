現在のマインドマップアプリにおいて、アプリを開いた（リロードした）直後にルートノードにキーボードフォーカスが当たらない不具合を修正してください。
React Flowの描画が完了する前にフォーカス処理が走って空振りしていることが原因です。

【要件: src/nodes/MindMapNode.tsx の修正】
1. `MindMapNode.tsx` 内にある、以下の初回マウント時の `useEffect` を探してください。
   ```typescript
   useEffect(() => {
     if (selected && !isEditing && data.label !== '') {
       buttonRef.current?.focus();
     }
   }, []);

2. この `if` 文の中の `buttonRef.current?.focus();` の呼び出しを、DOMのレンダリング完了を待つために `globalThis.requestAnimationFrame` の二重呼び出し（または `setTimeout`）でラップするように修正してください。

---

### 💡 なぜ `requestAnimationFrame` を二重にするのか？
React Flowのような複雑なDOM構造を持つライブラリは、コンポーネントがマウントされてから実際に画面に要素が配置されるまでにわずかなラグがあります。`requestAnimationFrame` を2回ネストすることで、「ブラウザが次のフレームを描画し終わった直後」という一番確実なタイミングでフォーカスを当てることができます。

これでリロード直後でも、すぐに矢印キーでの移動や `Space` キーでの編集などができるようになるはずです！
