現在のマインドマップアプリにおいて、画面にノードやキャンバスが表示されない（高さが0になってしまう）CSSの不具合を修正してください。
原因は `App.tsx` の一番外側の要素が `size-full` (`height: 100%`) になっていますが、親要素である `#root` に高さが指定されていないためです。

【要件: src/App.tsx の修正】
1. `App.tsx` の return 内にある、一番外側の `div` 要素のクラス名を `size-full` から `h-screen w-screen overflow-hidden` に変更してください。
これにより、親要素の高さに依存せず、画面いっぱいの高さを強制的に確保して React Flow を正しく描画できるようにします。
