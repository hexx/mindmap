# 課題解決プロンプト: コード重複・型安全性・マジックナンバーなど中程度の問題を修正する

## 1. 役割定義 (Persona)
あなたはコード品質の改善を専門とするソフトウェアエンジニアです。以下の複数の小〜中程度の問題をまとめて修正してください。

## 2. 背景・前提条件 (Context)

### 問題A: `focusNode` 関数が `App.tsx` と `MobileToolbar.tsx` で完全に重複
- **ファイル**: `src/App.tsx`, `src/components/MobileToolbar.tsx`
- **内容**: まったく同じ7行の関数が2箇所にコピペされている
- **修正方針**: `useFocusNode` カスタムフックに抽出し、両コンポーネントから共有する
```ts
// src/hooks/useFocusNode.ts を新設
export const useFocusNode = () => {
  const { fitView } = useReactFlow<MindMapNode, MindMapEdge>();
  return useCallback((nodeId: string) => {
    globalThis.requestAnimationFrame(() => {
      globalThis.requestAnimationFrame(() => {
        fitView({ nodes: [{ id: nodeId }], duration: 400, maxZoom: 1 });
      });
    });
  }, [fitView]);
};
```

### 問題B: Hono Clientの手動型アサーション
- **ファイル**: `src/utils/cloudMindmaps.ts`
- **該当箇所**:
```ts
export const client = hc<AppType>('/') as CloudMindmapRpcClient;
```
- **問題**: `CloudMindmapRpcClient` 型が手書きのため、`worker.ts` のAPIが変わっても型エラーが出ない
- **修正方針**: `as CloudMindmapRpcClient` を削除し、`hc<AppType>` の推論結果をそのまま使う。`CloudMindmapRpcClient` 型も削除する

### 問題C: ハードコードされたマジックナンバー
- 以下の数値が複数ファイルに散在している:
  - `250`（子ノードのXオフセット / レイアウト距離）: `useStore.ts`, `orgModeGraph.ts`
  - `100`（兄弟ノードのYオフセット）: `useStore.ts`
  - `300`（d3 tree の `nodeSize[1]`）: `useStore.ts`
- **修正方針**: 定数ファイル（例: `src/constants.ts`）に集約し、意味のある名前を付ける
```ts
export const LAYOUT = {
  CHILD_X_OFFSET: 250,
  SIBLING_Y_OFFSET: 100,
  TREE_NODE_HEIGHT: 300,
} as const;
```
