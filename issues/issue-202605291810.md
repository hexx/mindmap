useStore.tsのcreateNodeIdにおけるIllegal invocationエラーの修正

現在の `src/store/useStore.ts` にある `createNodeId` 関数で、ノードを追加しようとした際にブラウザのコンソールで `TypeError: Illegal invocation` エラーが発生して処理が止まってしまうバグがあります。

原因は `crypto.randomUUID` を変数に代入してから実行しているため、内部の `this` コンテキストが失われていることです。以下の修正を行ってください。

1. `createNodeId` 関数の実装を以下のように書き換え、`globalThis.crypto.randomUUID()` を直接呼び出すように修正してください。

```typescript
const createNodeId = () => {
  if (typeof globalThis.crypto?.randomUUID === 'function') {
    return globalThis.crypto.randomUUID();
  }
  return `node-${Date.now().toString(36)}-${Math.random().toString(36).slice(2, 8)}`;
};
