現在のマインドマップアプリにおいて、スマートフォンでホーム画面に追加（PWA）した際やブラウザのタブ上で、アイコンがデフォルトの文字（Wなど）になってしまい見分けがつきません。
マインドマップらしいアイコンをSVGで自作し、PWAとして正しく認識されるように以下の要件を満たすファイル群を作成・修正してください。

【要件1: SVGアイコンの作成 (public/icon.svg)】
1. プロジェクトルートの `public` ディレクトリ（なければ作成）の中に `icon.svg` を新規作成してください。
2. マインドマップを連想させるシンプルで視認性の高いデザイン（例: 中心ノードから左右にエッジと子ノードが広がっているネットワーク図）のSVGコードを出力してください。
3. `viewBox="0 0 512 512"` とし、背景は角丸の四角形（青系や白系など、アプリのテーマに合う色）にしてください。

【要件2: Web App Manifest の作成 (public/manifest.json)】
1. `public/manifest.json` を新規作成し、以下の内容を含むJSONを出力してください。
   - `name`: "Mindmap"
   - `short_name`: "Mindmap"
   - `start_url`: "/"
   - `display`: "standalone"
   - `background_color`: "#f8fafc"
   - `theme_color`: "#2563eb"
   - `icons`: 作成した `icon.svg` を指す設定（`src`: "/icon.svg", `type`: "image/svg+xml", `sizes`: "any" または "512x512"）を含めること。

【要件3: index.html の修正】
1. プロジェクトルートの `index.html` の `<head>` 内に以下のタグを追加してください。
   - `<link rel="icon" type="image/svg+xml" href="/icon.svg" />`
   - `<link rel="apple-touch-icon" href="/icon.svg" />`
   - `<link rel="manifest" href="/manifest.json" />`
   - `<meta name="theme-color" content="#2563eb" />`
