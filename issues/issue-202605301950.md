現在のマインドマップアプリにおいて、ルートノードから左側に展開されたノードへのエッジ（線）が、ノードを回り込んで交差してしまう不具合を修正してください。
原因は、ルートノードが左右両方にエッジを伸ばす必要があるのに、動的にハンドルの位置が切り替わっていないためです。以下の要件を満たすように実装を修正してください。

【要件1: MindMapNode.tsx の修正】
1. 現在の `isLeftSide` によるハンドルの位置の動的切り替えを廃止してください。
2. 代わりに、ノードの左側（`Position.Left`）と右側（`Position.Right`）の**両方**に、`type="source"` と `type="target"` のハンドルをそれぞれ配置してください。
3. React Flowのエッジが接続先を識別できるように、左側のハンドルには `id="left"`、右側のハンドルには `id="right"` と明確なIDを設定してください（必要であれば `left-source`, `left-target` のように分けても構いません）。
4. ハンドルの見た目や位置が崩れないように、既存の `mindmap-node__handle` クラスなどを適切に当ててください。

【要件2: useStore.ts のエッジ生成ロジックの修正】
1. エッジを生成・追加する各処理（`addChildNode`, `addSiblingNode`, `updateNodeParent`, `importGraph` など）において、親ノードと子ノードのX座標（`position.x`）を比較して接続方向を決定してください。
2. 子ノードが親ノードより左側（X座標が小さい）にある場合は、生成するエッジに `sourceHandle: 'left'`, `targetHandle: 'right'`（要件1で設定したID）を明示的に指定してください。
3. 子ノードが親ノードより右側にある場合は、エッジに `sourceHandle: 'right'`, `targetHandle: 'left'` を指定してください。

【要件3: applyAutoLayout の拡張】
1. オートレイアウト実行後（`d3-hierarchy` による計算後）は、ノードが左右どちらに配置されるか（X座標）が変わる可能性があります。
2. そのため、ノードの新しい `position` を計算し終わった後、すべての `edges` を再評価し、新しい親子のX座標の関係に基づいて各エッジの `sourceHandle` と `targetHandle` を更新する処理を追加してください。
