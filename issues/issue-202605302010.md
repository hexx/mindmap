前回のクラウド保存機能（Cloudflare Workers + D1）を拡張し、クラウドに保存されたマインドマップの一覧を表示して、「選択（読み込み）」および「削除」ができる管理モーダル画面を実装してください。
以下の要件を満たすように、バックエンドAPI、Zustandストア、UIコンポーネントを実装・修正してください。

【要件1: バックエンドAPIの拡張】
1. 前回の `schema.sql` に、一覧表示用の `title` カラム（TEXT）を追加するか、保存時にルートノードのラベル（またはユーザーが入力した名前）をタイトルとして保存できるように調整してください。
2. 以下の2つのAPIエンドポイントを追加してください：
   - `GET /api/mindmaps`: D1データベースに保存されているすべてのマインドマップのメタデータ（`id`, `title`, `created_at`）の一覧を配列で返す。
   - `DELETE /api/mindmap/:id`: 指定されたIDのデータをD1データベースから削除する。

【要件2: useStore.ts（Zustandストア）の拡張】
1. ストアの状態（`MindMapState`）に、クラウド上のマインドマップ一覧を保持する `cloudMindmaps` 配列（型は `{ id: string; title: string; created_at: string }[]`）を追加してください。
2. 以下の2つの非同期アクションを追加してください：
   - `fetchCloudMindmaps: async () => Promise<void>` : `GET /api/mindmaps` から一覧を取得し、`cloudMindmaps` 状態を更新する。
   - `deleteFromCloud: async (id: string) => Promise<void>` : `DELETE /api/mindmap/:id` を呼び出してクラウドから削除し、成功したら `fetchCloudMindmaps` を再実行して一覧を最新にする。
3. 既存の `saveToCloud` アクションを修正し、保存完了時にも `fetchCloudMindmaps` を呼び出すようにしてください。

【要件3: 管理画面コンポーネント（src/components/SavedMindmapsModal.tsx）の新規作成】
1. 保存されたマインドマップを一覧表示するモーダルダイアログコンポーネントを新規作成してください。
2. このコンポーネントは、プロパティとして `isOpen: boolean` と `onClose: () => void` を受け取るようにします。
3. モーダルが開かれたとき（`useEffect`）に、ストアの `fetchCloudMindmaps` を実行して最新の一覧を読み込んでください。
4. UIは、現在のアプリのシンプルなデザイン（白背景、角丸、シャドウなど）に馴染むスタイリッシュなテーブル、またはリスト形式にしてください。
5. 各リストアイテムには以下の情報を表示し、右側に操作ボタンを配置してください：
   - マインドマップのタイトル（またはルートノード名）
   - 保存日時（フォーマットされた文字列）
   - 「開く」ボタン (クリックで `loadFromCloud(id)` を実行しモーダルを閉じる)
   - 「削除」ボタン (クリックで `deleteFromCloud(id)` を実行。削除前に `confirm` で確認を入れる)
6. リストが空の場合は「保存されたマインドマップはありません」と表示してください。

【要件4: App.tsx への組み込み】
1. `App.tsx` 内で、モーダルの開閉状態を管理するローカルステート（`isModalOpen`, `setIsModalOpen`）を追加してください。
2. 「クラウドから読込」ボタンをクリックした際に、前回の `prompt` ではなく、この `SavedMindmapsModal` を開くように変更してください。
3. モーダルコンポーネントを `<ReactFlow>` の外側（`App` の return 内の最下部など）に配置してください。
