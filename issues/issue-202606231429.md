# 課題解決プロンプト: マインドマップアプリのキーボード操作をドキュメントに記載する

## 1. 役割定義 (Persona)
あなたは技術ドキュメントのエキスパートです。以下のコンテキストとゴールを基に、ユーザーがすぐに参照できるキーボード操作一覧を作成してください。

## 2. 背景・前提条件 (Context)
- **現状発生している問題**: マインドマップアプリには多数のキーボードショートカットが実装されているが、利用者向けのドキュメントが存在しないため、ユーザーが操作方法を発見できない
- **関連ファイル/コード**:
  - `src/App.tsx` — メインのキーボードイベント処理（Undo/Redo、フォーカス移動、ノード追加・削除）
  - `src/nodes/MindMapNode.tsx` — ノード単位のキーボードイベント処理（編集モード切替、ラベル入力）
  - `README.md` — プロジェクトのドキュメントファイル

## 3. 解決すべきゴール (Goal & Objective)
- [ ] `README.md` に「キーボード操作一覧」セクションを追加する
- [ ] 以下の操作を網羅的に記載する:

### ノード選択時
| キー | 操作 |
|------|------|
| Tab | 子ノードを追加して編集モードに入る |
| Enter | 兄弟ノードを追加して編集モードに入る |
| Delete / Backspace | 選択中のノードを削除（ルートは不可） |
| Space | 編集モードに入る |
| 文字キー (A-Z等) | 編集モードに入り、入力された文字でラベルを上書き |
| Arrow Up | 上の兄弟ノードへフォーカス移動 |
| Arrow Down | 下の兄弟ノードへフォーカス移動 |
| Arrow Left | 親ノードへフォーカス移動 |
| Arrow Right | 子ノードへフォーカス移動 |

### グローバル操作
| キー | 操作 |
|------|------|
| Ctrl+Z (Cmd+Z) | 操作を元に戻す (Undo) |
| Ctrl+Shift+Z (Cmd+Shift+Z) | 操作をやり直す (Redo) |
| Ctrl+Y (Cmd+Y) | 操作をやり直す (Redo) |

### 編集モード時
| キー | 操作 |
|------|------|
| Enter | 編集を確定し、兄弟ノードを追加 |
| Tab | 編集を確定し、子ノードを追加 |
| Escape | 編集をキャンセル |
| Backspace (空ラベル時) | ノードを削除 |

- [ ] テーブル形式で見やすく記載する
- [ ] macOSとWindows/Linux両方のキーを記載する（Cmd/Ctrl）

## 4. 期待する成果物 (Output Format)
- `README.md` に追加された「キーボード操作一覧」セクション
- テーブル形式で整理された操作一覧
- macOS/Windows/Linux両対応のキー表記
