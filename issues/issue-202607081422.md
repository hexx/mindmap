# 課題解決プロンプト: TanStack Queryを導入し、クラウドAPI通信の状態管理を簡素化する

## 1. 役割定義 (Persona)
あなたは React の状態管理とサーバー状態の分離に精通したフロントエンドエンジニアです。zustand ストアに混在しているサーバー状態（クラウドAPI通信）を TanStack Query（React Query）に移行し、コードの簡素化と保守性の向上を実現してください。

## 2. 背景・前提条件 (Context)

### 現状の課題
現在、クラウドマインドマップのAPI通信（取得・保存・読み込み・削除）がすべて `src/store/useStore.ts` の zustand ストア内に手書きで実装されています。これにより以下の問題が生じています：

- **ボイラープレートの多さ**: ローディング状態・エラーハンドリング・再取得が手動管理（約60行）
- **責務の混在**: UI状態（nodes, edges）とサーバー状態（cloudMindmaps）が同一ストアに混在
- **キャッシュ不在**: 一覧データを使い回せず、毎回APIを呼び出している
- **手動の再取得**: 保存/削除後に `fetchCloudMindmaps()` を手動で呼び出している

### 対象となるコード
- `src/store/useStore.ts`: `fetchCloudMindmaps`, `saveToCloud`, `loadFromCloud`, `deleteFromCloud` の4メソッドと `cloudMindmaps` 状態
- `src/components/SavedMindmapsModal.tsx`: クラウド一覧を表示するモーダル（`cloudMindmaps` を使用）
- `src/App.tsx`: `saveToCloud`, `handleOpenCloudMindmaps` など

### 技術スタック
- React 19, TypeScript, zustand（状態管理）, Hono RPC（APIクライアント）
- APIエンドポイント: `GET /api/mindmaps`, `POST /api/mindmap`, `GET /api/mindmap/:id`, `PUT /api/mindmap/:id`, `DELETE /api/mindmap/:id`

## 3. 解決すべきゴール (Goal & Objective)
- [ ] `package.json` に `@tanstack/react-query` を追加し、`App.tsx`（または `main.tsx`）に `QueryClientProvider` を設定する
- [ ] `useStore` から `cloudMindmaps` 状態と4つのクラウド操作用メソッド（`fetchCloudMindmaps`, `saveToCloud`, `loadFromCloud`, `deleteFromCloud`）を削除する
- [ ] 以下のカスタムフックを新規作成する:
  - `src/hooks/useCloudMindmaps.ts` — `useQuery` で一覧取得 + `useMutation` で保存/削除
  - 保存成功時は `queryClient.invalidateQueries({ queryKey: ['mindmaps'] })` で一覧を自動再取得
- [ ] `SavedMindmapsModal.tsx` を修正し、zustand ストアの代わりに `useCloudMindmaps` フックを使用する
- [ ] `App.tsx` の `handleSaveToCloud` を修正し、ストアメソッドの代わりに `useCloudMindmaps` フックの mutation を使用する
- [ ] ローディング状態・エラー状態を適切にUIに反映する（`isLoading`, `isError`, `isPending`）
- [ ] 型安全性を維持すること（Hono RPC クライアントとの連携）
- [ ] 既存のテスト（`useStore.test.ts`）を修正し、TanStack Query を使用するテストに更新する（`@tanstack/react-query` のテストユーティリティを使用）
- [ ] `npx tsc -b` および `npx vitest run` が全件パスすること

## 4. 期待する成果物 (Output Format)
- 新規ファイル: `src/hooks/useCloudMindmaps.ts`
- 修正ファイル: `src/store/useStore.ts`, `src/main.tsx`, `src/App.tsx`, `src/components/SavedMindmapsModal.tsx`, `src/store/useStore.test.ts`
- `package.json` への依存追加
- ビルド・テストのパス確認結果
- 移行前後のコード行数比較（目安）

## 5. 実行開始の合図
このプロンプトを理解したら、「タスクを開始します」と宣言し、直ちに現在の `useStore.ts` のクラウド関連コードの解析から始めてください。
