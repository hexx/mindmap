# 課題解決プロンプト: GitHub Actions CI の作成

## 1. 役割定義 (Persona)
あなたは高度なソフトウェアエンジニアおよび DevOps のエキスパートです。以下のコンテキストとゴールを基に、正確かつ効率的な CI ワークフローを構築してください。

## 2. 背景・前提条件 (Context)
- **現状発生している問題**: このプロジェクトには GitHub Actions の CI ワークフローが存在せず、PR 作成時やプッシュ時に自動でコード品質チェックが行われない。
- **プロジェクト構成**:
  - フレームワーク: React + Vite + TypeScript
  - パッケージマネージャー: npm
  - Lint: oxlint（`oxlint -D correctness -D suspicious -D perf -A no-map-spread`）
  - テスト: vitest
  - ビルド: `tsc -b && vite build`
  - デプロイ先: Cloudflare Workers (wrangler)
- **関連ファイル/コード**:
  - `/workspace/package.json` - スクリプト定義
  - `/workspace/.github/workflows/` - 存在しないため新規作成が必要

## 3. 解決すべきゴール (Goal & Objective)
- [ ] `.github/workflows/ci.yml` を作成し、プッシュおよび PR 時に自動実行される CI パイプラインを構築する
- [ ] Lint チェック（oxlint）を含める
- [ ] 型チェック（tsc）を含める
- [ ] 単体テスト（vitest）を含める
- [ ] ビルド確認（`npm run build`）を含める
- [ ] Node.js のバージョンは `.node-version` または `package.json` の `engines` フィールドを参照する（なければ LTS を使用）

## 4. 期待する成果物 (Output Format)
- `.github/workflows/ci.yml` ファイル
- 各ジョブの役割と流れの簡潔な解説

## 5. 実行開始の合図
このプロンプトを理解したら、「タスクを開始します」と宣言し、直ちにステップ2の「関連ファイル」の解析から始めてください。
